# Qodo review notes

One file per pull request, named after its branch, such as
`day-01-ch12-layout.md`. For each Qodo comment:

| Column | Meaning |
|---|---|
| Finding | What Qodo said, in a few words, with a link to the comment |
| Decision | Accepted, rejected, or deferred |
| Reason | Why, checked against the code and the Django 6.1 docs |
| Change | The commit that applied it, or the chapter it is deferred to |

Each note ends with what the review was useful for, what was
questioned, and what it missed. Accepted changes to code an existing
chapter shows are listed as proposed book revisions
(see [../../BOOK_SYNC.md](../../BOOK_SYNC.md)).
